RAMI · FLASH

Firmware universel ESP32 — flash USB directement depuis le navigateur
  1. Branche l'ESP32 en USB.
  2. Choisis la version, puis Installer (neuf) ou Mettre à jour.
  3. Configure WiFi / MQTT / capteurs via le portail / la console.
—
Navigateur non supporté — Chrome/Edge/Opera. La page doit être en HTTPS.
Le flash USB écrit l'image complète et efface la config (WiFi/MQTT/capteurs) — c'est normal pour un 1er flash. Pour mettre à jour sans rien perdre, utilise l'OTA depuis la console (l'ESP se met à jour lui-même par WiFi, la config est conservée).
