RAMI · FLASH

Firmware universel ESP32 — flash USB directement depuis le navigateur
  1. Branche l'ESP32 en USB.
  2. Clique sur Installer et choisis le port série.
  3. Au 1er démarrage, configure WiFi / MQTT / capteurs via le portail captif de l'ESP.
Navigateur non supporté — utilise Chrome, Edge ou Opera (Web Serial API). La page doit être servie en HTTPS (c'est le cas sur GitHub Pages).
Flashe toujours la dernière release publiée (releases/latest). Les mises à jour suivantes se font ensuite par OTA via le fog, sans recâbler l'USB.
